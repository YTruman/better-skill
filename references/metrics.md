# 五维量化标尺（会诊评级）

> D 模式必读；B 模式定级时加载。**诚实原则：下表水位线来自官方 300+ 库语境，本地环境未系统校准；引用时必须注明来源状态，有本地实测数据时优先用实测。**

## 五个维度

### 1. 任务完成效率（Tool Call Efficiency）
- 定义：完成同一复杂任务的平均工具调用/消息往返次数。
- 官方水位线：高阶 Skill 通过工作流编排 + 侦察并行，往返次数减少 30%+；无多余澄清询问。
- 本地测法：同任务跑裸 prompt vs 带 Skill 各 3 次，数往返。

### 2. Token 节省率（Token Economy）
- 定义：单位产出消耗的背景 Token 数。
- 官方水位线：远低于对话中重复粘贴 prompt；严禁全量重写长文档，只传 diff。
- 本地测法：读会话 token 统计（Harness 面板可见消耗），对比 Skill 触发前后的单位产出成本。

### 3. 触发准确率（90% 原则）
- 定义：10-20 个相关多元查询（含改述 paraphrase）中自动唤醒的成功率。
- 官方水位线：≥ 90%。需要用户显式点名或反复提特定词才能唤醒 = description SEO 失败。
- 本地测法（2026-08 官方标准化方案，详见 `eval-loop.md` §2）：20 条查询 = 8-10 条应触发（同意图多种说法）+ 8-10 条**近似误伤负例**（同关键词、真意不同）；每条 3 遍取稳定值；60/40 分训练/保留集，按保留集分数选优 description。官方报告此法优化幅度可达 83.3%（官方库语境，本地待实测）。
- 机制提醒：模型只对"自己搞不定的复杂任务"查技能——太简单的查询测不出触发，出题要够真实够复杂。

### 4. 无修改采纳率（ZSAR，Zero-Shot Acceptance Rate）
- 定义：产出物不做任何人工修正直接通过审核落地的概率。衡量针对性的终极 KPI。
- 官方水位线：高阶实战任务 ≥ 85%；支持靶向迭代（对 15% 错误做精准 Prompt Patch，而非整体重刷）。
- 本地测法：记录该 Skill 最近 N 次真实产出，人工零修改通过的比例。

### 5. 自治治理等级（C/B/A/S）
| 等级 | 名称 | 含义 | 人类角色 |
|---|---|---|---|
| C | Co-Pilot | 提供参考 | 每步确认 |
| B | Reviewer | AI 全稿 | 修正性审计 |
| A | Autonomous | 标准环境自动执行 | 日志抽检 |
| S | Supervised Self-Evolve | 自回归测试 + 自动优化闭环 | 只看趋势 |

评级时标注该 Skill **当前等级**与**目标等级**；跨级升级必须在 Exit Criteria 里写明对应的人类中断器配置。

## 会诊输出格式（D 模式产出物）

```markdown
# Skill 会诊报告：<A> vs <B> · <日期>

## 五维对比
| 维度 | <A> | <B> | 判据（证据） |
|---|---|---|---|
（五维逐行；无数据的维度写"未实测"，禁止拍脑袋填数）

## 裁决
- 一句话结论：<留谁/合并/退役/各司其职>
- 分工建议：...
- 执行移交：组合级动作由 skill-stocktake 执行

## 校准状态声明
本报告引用的水位线为官方库语境；本地实测数据：<有/无，来源>。
```

## 使用纪律

- 禁止把未实测的数字当结论；未实测就写"未实测"。
- 横评只比**同任务域**的 Skill；跨域比较无意义。
- 任何"退役/合并"结论只做建议，执行权在用户 + stocktake。
